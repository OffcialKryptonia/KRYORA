# KRYORA delivery roadmap

1. **Framework migration:** preserve the existing experience while moving the app shell and API proxy to Next.js App Router.
2. **Catalogue reliability:** verify provider contract, rights, uptime, schema, caching, and failure handling; add approved metadata sources.
3. **Discovery:** refine search, category pages, title pages, and responsive browsing.
4. **Accounts:** introduce Supabase Auth and secure profiles after credentials and project access are configured.
5. **Personalization:** watchlists, playback progress, and continue-watching backed by server-side authorization.
6. **Administration:** protected `/admin` with role checks, content management, settings, and audit history.
7. **Authorized playback:** select a licensed delivery provider and implement entitlement-aware playback only for authorized content.
8. **Production readiness:** accessibility, performance, security review, observability, CI, and deployment verification.

No milestone is complete solely because its UI exists. Verify implementation and tests before reporting completion.
